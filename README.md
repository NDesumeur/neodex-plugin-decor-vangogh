# Décor Nuit étoilée pour NeoDex

Une nuit étoilée, à la manière de Van Gogh : un décor en pixel art pour le fond de NeoDex, qui bouge doucement derrière tes fenêtres.

*English version: [README.en.md](README.en.md)*

S'installe depuis NeoStore, rayon **Thèmes et décors**, puis se choisit dans Paramètres › Décor. Il entre aussi dans le tirage « Aléatoire » et peut recevoir une étoile pour « Mes favoris ».

- Fonctionne sur PC et sur téléphone. Demande NeoDex 3.3.9 ou plus.
- Ne demande aucune autorisation et ne contient aucun code : le dessin est fait par NeoDex, le plugin le débloque.

Avant NeoDex 3.3.9, ce décor était intégré à NeoDex. Seuls les décors sobres le sont encore.
