# Starry night decor for NeoDex

A starry night, in the manner of Van Gogh: a pixel art decor for NeoDex's background, moving gently behind your windows.

*Version française : [README.md](README.md)*

Install it from NeoStore, **Themes and decors** shelf, then pick it in Settings › Decor. It also joins the "Random" draw and can get a star for "My favourites".

- Works on PC and on phone. Needs NeoDex 3.3.9 or later.
- Asks for no permission and holds no code: NeoDex draws it, the plugin unlocks it.

Before NeoDex 3.3.9, this decor came with NeoDex. Only the sober decors still do.
